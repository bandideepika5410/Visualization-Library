# Visualization-Library
Visualization Library using python
# 🟢 Task 1 — Beginner Level: Visualization Library Documentation

## 📌 Objective
Created a comprehensive documentation guide for 2 Python 
visualization libraries — Matplotlib and Seaborn — focusing 
on the variety of graphs each library can generate, with 
practical code examples.

---

## 📚 Libraries Covered
- **Matplotlib**
- **Seaborn**

---

## 📊 Graph Types Documented

### Matplotlib
| Graph Type | Use Case |
|------------|----------|
| Line Plot | Trends over time |
| Bar Chart | Comparing categories |
| Histogram | Data distribution |
| Scatter Plot | Relationship between variables |
| Pie Chart | Proportions |

### Seaborn
| Graph Type | Use Case |
|------------|----------|
| Heatmap | Correlation matrix |
| Box Plot | Outlier detection |
| Violin Plot | Distribution + density |
| Pair Plot | Multi-variable relationships |
| Count Plot | Frequency of categories |

---

## ⚖️ Library Comparison

| Feature | Matplotlib | Seaborn |
|---------|------------|---------|
| Ease of Use | Moderate | Easy |
| Customization | High | Medium |
| Interactivity | Low | Low |
| Statistical Plots | Limited | Rich |
| Large Datasets | Good | Good |
| Built on | - | Matplotlib |
